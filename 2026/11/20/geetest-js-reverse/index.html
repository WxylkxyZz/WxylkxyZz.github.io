调试

每次滑动滑对滑错都会发一个请求,跟栈进去打断点,一直跟会跟到w的定义处

PS:也可直接搜索特征码"\u0077"

w = h+u

u

  1. 先找u(没有参数好弄一点) 打断点跟进，发现return了一个e -> u=e -> 看e的定义

var e = new U()[$_CBFJN(392)](this[$_CBGAK(744)](t)) -> new U()["encrypt"](this["$_CCEc"](t))

PS:

  1. typeof(t)=undefind，typeof(this[$_CBGAK(744)](t))=string 提前看好变量类型 下面return避免出错
  2. 我多次调试发现t()断不住，后面多尝试了几次发现只有刷新页面第一次点击’点击…进行验证’才会断住，只刷新滑块不行

this["$_CCEc"](t) = Ot-> Ot=rt() -> rt()=t()+t()+t()+t() -> t()

t() = return (65536 * (1 + Math['random']()) | 0)['toString'](16)['substring'](1)

this[$_CBGAK(744)](t) = t()四次调用相加,改写替换即可

  1. new U()[‘encrypt’] 看到这个词大概猜是rsa

  2. 看U()这个类中的setPublic函数,可以找到公钥模数和公钥指数,得到公钥后我们可以自己复现对照一下看是否是标准rsa加密。

参数 l

r[$_CAIAK(744)]() = randomStr()
l = V["encrypt"](gt["stringify"](o), randomStr())
手动解混淆后， 发现gt["stringify"]()跟JSON.stringify()作用一样，
也就是说要找到

  1. 参数o
  2. 加密方法V["encrypt"]

参数 o

向上找几行即可找到o的定义处, 发现是个obj多打印几次看看哪些值有变化

4个参数发生变化
userresponse、passtime、aa、rp
找四个参数即可

aa

aa = e，e又是function(t, e, n)传进来的，往上跟栈，e=l

l = n[$_DAAAU(985)][$_CJJJU(1075)](n[$_CJJJU(985)][$_CJJJU(1073)](), n[$_CJJJU(67)][$_CJJJU(1033)], n[$_DAAAU(67)][$_CJJJU(345)]);
解混淆
l = n["$_CICO"]["$_BBED"](n["$_CICO"]["$_FD_"](), n["$_CJk"]["c"], n["$_CJk"]["s"])
大概就是一个函数传了三个参数
分别查看三个参数，发现后两个好像见过 (在分析请求中) 进行对比发现是同一个值c、s，所以找第一个参数即可
第一个参数是一个函数返回的 进入函数分析
第一行开始做事的地方

打印this[$_BEGJO(359)]像是个轨迹值，包含16个数组的obj，在经过这个函数后返回了一个15个数组的obj
看到函数中做了一些运算，应该是对轨迹数组做了一些处理。
然后定义了三个空列表

最后return了

解混淆后

new ct(t)[$_BEHAO(59)]() 创建了一个新对象,t是传给构造函数的参数, 调用该对象的$_BEHAO(59)方法，然后把传入了一个自执行函数,这个func把t做参数进行运算分别往三个空数组里push值，最后把返回三个数据的拼接值

改写加扣代码即可 传入轨迹组track

测试对不对

userresponse

userresponse = H(t, i["challenge")

  1. i["challenge")就是我们请求/get.php?时候返回的challenge
  2. t是通过function(t, e, n)传进来的 所以往上跟栈
    在r[$_DAAAU(1051)](u, l, n[$_DAAAU(852)])调用了function(t, e, n)
    也就是说 t=u = _
    _ = e ? n[$_DAAAU(1028)][$_CJJJU(203)] : t[$_CJJJU(960)]() / a - n[$_CJJJU(930)]
    解混淆
    _ = e ? n["lastPoint"]["x"] : t["$_BGCr"]() / a - n["$_CIAT"]
    e是undefind类型所以一定会等于后半段，但是多次测试，前后两个值相等
    前面值字面像是最后一个x的位置的值调试对比看看
passtime

passtime = n,也是由function(t, e, n)传进来的,继续跟栈，
这里不着急往上跟, 分析一下userresponse用到了轨迹值，(x,y,z)是坐标跟时间，大胆猜测passtime会不会就是最后的z呢？ 测试对比下. 还真是

rp

o[$_CAIAK(793)] = X(i[$_CAIAK(122)] + i[$_CAIAK(134)][$_CAIAK(187)](0, 32) + o[$_CAHJS(725)])

解混淆
o["rp"] = X(i["gt"] + i["challenge"]["slice"](0, 32) + o["passtime"])

比较简单传值即可
